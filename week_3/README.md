# SQL Assignment – Week 3

## Files Included

* `assignment_3.ipynb` – SQL assignment solutions using the Superstore dataset and SQLite.
* `Sample_Superstore.csv` – Dataset used for analysis.

## Tasks Done

* Imported the Superstore dataset into SQLite.
* Created normalized tables: `customers`, `orders`, `products`, and `order_details`.
* Inserted data into tables using `SELECT DISTINCT`.
* Solved SQL problems using Subqueries, CTEs, and Window Functions.
* Calculated customer-wise total sales and sales rankings.
* Identified customers with above-average sales.
* Assigned row numbers to orders using `PARTITION BY`.
* Retrieved top and bottom customers based on sales performance.
* Analyzed customer order patterns and highest order values.
* Built a final query combining `JOIN`, `CTE`, and `Window Functions` to generate customer sales insights.
