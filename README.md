# Celebal Technologies Data Engineering Internship

This repository contains all assignments and learning completed during my **8-week Data Engineering Internship** at **Celebal Technologies**.

## Internship Overview

The internship provided hands-on experience in modern Data Engineering concepts, SQL, Python, Apache Spark, Databricks, Delta Lake, and cloud-based data processing workflows.

Throughout the internship, I worked on designing data transformations, writing optimized SQL queries, building Spark applications, implementing Delta Lake operations, and understanding industry-standard data engineering architectures.
